# Catalog — AI Skill Starter Bundle (21 skills)
- **ai-council** — Decide with a five-seat adversarial council — Investor, Customer, Engineer, Risk Counsel, Skeptic — that argues in three rounds and votes GO / GO_WITH_CONDITIONS / NO_GO, with conditions merged and disagreements recorded, not smoothed over.
- **ai-receptionist** — A deterministic receptionist core for small businesses — answers FAQs, hours and prices only from the business's own JSON data, books appointments into genuinely free slots (no double-booking, no closed days), captures callbacks, and escalates complaints and unanswerable questions to the human owner.
- **btc-race-strategy** — A volatility-scaled dip-buying strategy for cbBTC/USDC on one-minute bars. Long-only, tranched execution, trailing exit, hard stop, drawdown brake and a trend-hold fallback. Use when an agent needs a complete, deterministic BTC dip-buying bot that trades rarely, only on high-quality dips, and keeps bad days small.
- **buyer-panel** — Test a product page or offer against a five-persona simulated buyer panel — Skeptic, Bargain Hunter, Impulse Buyer, Technical Buyer, Busy Owner — each scoring willingness to buy, quoting the exact line that decided them, and naming their top fix.
- **faceless-channel** — Turn one niche into a complete 30-day faceless YouTube/TikTok channel pack — content calendar, a filmable script per slot in the Talking-Head format, posting schedule, checklists and setup templates for 5 niches.
- **fix-guide** — Fix every SkillAudit finding — a remediation playbook keyed to the scanner's rule ids, with the safe pattern to replace each dangerous one and how to verify the fix.
- **git-forge** — A GitHub-compatible git forge in dependency-free TypeScript - git smart HTTP, REST v3, GraphQL v4 and an MCP endpoint over one in-memory store. Use when an agent needs to build, study or extend a git hosting backend with zero npm dependencies.
- **gta6-twitch-forecast** — A dependency-free Python forecaster for launch-day Twitch viewership - an hour-1 anchored comparable ensemble producing five quantiles for hours 2-24. Use when an agent needs quantile forecasts for a launch event from a single early data point plus comparable launches.
- **hardening** — Harden an AI agent skill that passed review with notes — least-privilege environment, network allowlists, write scoping, disclosure writing and safe structure — until it passes a clean re-audit.
- **invoice-generator** — Generate a professional invoice (HTML, print/PDF-ready) from structured business, client and line-item data, with correct subtotal, discount, tax and multi-currency totals, EN/ID labels, PAID/UNPAID stamp, payment instructions and accent colors.
- **launch-autopilot** — Turn one product's facts into a complete launch pack — Product Hunt, DevHunt and Show HN copy in each platform's voice, social posts, an asset checklist and an hour-by-hour launch-day schedule.
- **skill-audit** — Audit an AI agent skill for security risks before installing or publishing it — credential access, environment reads, network calls, execution, file writes and exfiltration-shaped combinations — and produce a graded report with file-and-line evidence.
- **skill-reviewer** — Review an AI agent skill's SKILL.md and instructions line by line for hidden instructions, instruction disguise, scope creep and social-engineering traps that pattern scanners cannot see.
- **story-to-shorts** — Turn one topic into a complete 45–60 second Shorts production pack — hook-first script in a proven retention framework, timed scene list, overlays, title and hashtags — ready for the Talking-Head pipeline.
- **talking-head-kit** — Produce vertical talking-head videos from a script, one portrait photo and a voice track — caption splitting, word-timed subtitles, shot lists and an offline ffmpeg render pipeline.
- **telegram-summarizer-bot** — A complete Telegram bot blueprint that summarizes long pasted texts and charges users per summary with Telegram Stars credits — free trial, SQLite credit ledger, validated idempotent payments.
- **threat-patterns** — A field guide to known attack patterns against AI agent skills — credential theft, exfiltration shapes, instruction disguise, wallet traps, typosquatting and update-channel hijack — with the tell that exposes each one.
- **tiny-chess-engine** — A complete deterministic chess engine in a few KB of dependency-free Python - negamax alpha-beta, transposition table, quiescence, tapered evaluation. Use when an agent needs a small embeddable chess engine or wants to study compact engine design.
- **token-radar** — A pre-token protocol screener that ranks protocols by implied launch value - TVL times a category multiple learned from tokenized peers, adjusted for 7-day momentum and age. Use when an agent needs a transparent, reproducible way to rank pre-token protocols and plan around potential launches.
- **trend-scout** — Research what actually happened around a topic in the last 30 days — Hacker News, new GitHub repos and Google News — and synthesize a brief where every claim carries its date and source.
- **ugc-ad-generator** — Turn one product (name, price, benefits, audience) into 10 filmable UGC-style ad variants — script in the Talking-Head format, shot list, timed captions and hook line per angle — with a deterministic banned-claim compliance guard.
